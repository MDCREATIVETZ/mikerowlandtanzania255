# Mike Rowland Tanzania Limited Website

This folder is ready for a normal static website host or GitHub Pages.

## Upload to GitHub

1. Open your GitHub repository.
2. Upload every file and folder inside this folder to the repository root.
3. Commit the upload.
4. In GitHub, open Settings > Pages.
5. Under Build and deployment, choose Deploy from a branch.
6. Select the main branch and / (root), then save.

## Replace the images

Open assets/images and replace any PNG with your own photograph. Keep the same filename so no HTML changes are needed. Recommended banner size: 1920 x 1080 pixels.

## Update contact details

Search the HTML files for the phone number or email address and replace it where needed. The floating WhatsApp button currently opens +255 767 692 003.

## Main files

- css/style.css contains all styling.
- js/main.js controls the mobile menu, dropdowns and small animations.
- index.html is the Home page.
- Every company profile section has its own HTML page.
- gallery.html contains the filterable project gallery.
- Original company images are stored in assets/images/company-media.
